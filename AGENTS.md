# Smart Node-Scheduler

This repository follows the Smart Node-Scheduler v0.1 implementation instructions provided by the user in `AGENTS_Smart_Node_Scheduler.md`.

## Environment Gate

- Acceptance environment is Python `>=3.11,<3.13`.
- Test results from Python 3.14 or Python 2.7 are not acceptance evidence.
- All installs and tests must run through the project virtual environment Python, for example `.\.venv\Scripts\python.exe`.
- Do not add runtime entries such as `python>=3.11` to `requirements.txt`.
- Python runtime limits belong only in `pyproject.toml` as `requires-python`.
- If Python 3.11 or 3.12 is unavailable, stop environment verification and report the missing runtime instead of installing dependencies into another Python version.
