## 0. 한 줄 요약

BOQ만 import 하면 → 지층·공법별 생산성 원단위로 공기를 자동 산출하고 →
단계별 굴착 모델로 장비 what-if를 돌리고 → 3개 문서 간 수량 불일치를 자동 검증한다.
이것이 P6/MS Project가 기본 제공하지 못하는 MEP·토공 도메인 차별점이다.

## 2. 기능 1 — 지층·공법별 생산성 원단위 라이브러리 (최우선)

### 목적
사용자 수동 duration 입력을 제거하고, BOQ → 공기 초안 자동 생성.

### 구현 단계
1. `import_excel`에 **점-깊이(`…`) WBS 파서** 추가 — 내역서 들여쓰기를 WBS 레벨로 복원.
2. BOQ `규격` 컬럼에서 지층 태깅 — `매립토 / 풍화토 / 풍화암 / 기반암(미진동발파) / 기반암(할암)`.
3. `earthwork_productivity.json` 로드 → `수량 ÷ (생산성 × 장비대수)` = duration.
4. 현장 원단위 우선, 없으면 이론치 + 보정계수 적용(`_pick_rate`).

### 핵심 수치 (추출 완료)
| 공종/지층 | 현장 적용 | 이론(표5.22) | 보정계수 |
|---|---|---|---|
| C.I.P 천공(T4) | 120 m/일·대 | — | — |
| H-PILE 천공(토네이도) | 80 m/일·대 | — | — |
| ADG 차수 | 150 m/일 | — | — |
| 어스앵커 | 8공/일 (1단 양생 후 2단) | — | — |
| 터파기 풍화토 | 585 m³/일 | 600 m³/일·세트 | 검토필요 |
| 터파기 연암 | 30 m³/일·대 (미진동) | 200 m³/일·세트 | **0.15** |
| 터파기 경암 | 30 m³/일·대 (할암 병행) | 150 m³/일·세트 | 0.20(검토) |

> 암반 보정계수 0.15는 도심지 미진동/할암 공법의 현장 저하율로, 본 라이브러리의 핵심 가치다.

## 3. 기능 2 — 단계별 굴착 모델 + 장비기반 역산

### 목적
토공사를 액티비티가 아닌 **"단계 × 지층" 매트릭스**로 모델링하고,
`덤프 N대·백호 N대` 입력 시 공기 즉시 재계산(what-if).

### 검증된 산출 결과 (`earthwork_estimator.py` 실행)
- 최대심도 17.79m = 7단계 깊이 합과 일치(모델 정합성 확인).
- 안전평가서 적용기간 합 = **175일**, 이론 산정기간 합 = 93일 → 평균 보정계수 **1.88**.
- 현장 미진동 원단위(30 m³/대)로 백호 7대 재계산 시 암반 단계가 **65~85일** → 적용기간 25일과 큰 차이.

### 미해결 발견 (검증 필요)
> 표5.23 적용기간(25일/단계)은 표5.22 **이론** 원단위(연암 200) + 패딩으로 산정된 값이다.
> 반면 공정표의 현장 미진동 원단위(연암 30/대)로 재계산하면 같은 단계가 2.6배 길어진다.
> 즉 **안전평가서 적용기간 자체가 암반 구간을 과소평가**했을 가능성이 있다.
> → 기능 5(교차검증)가 이 불일치를 자동 플래그해야 한다. (어느 원단위가 실측에 맞는지는 현장 데이터로 확정)

## 4. 기능 5 — 교차검증 (Quantity / Rate Reconciliation)

### 목적
세 문서를 함께 import할 때 수량·생산성 불일치를 자동 검출 → "내역과 공정표가 따로 논다" 문제 차단.

### 검출된 불일치 (홍은동 실데이터)
| 항목 | BOQ(발주내역) | 공정표 | 비고 |
|---|---|---|---|
| 터파기 풍화토 | 10,808 m³ | 17,229 m³ | **+6,421 m³ 불일치** (매립토 합산해도 15,183으로 여전히 차이) |
| 터파기 암반(풍화암+미진동+할암) | 51,786 m³ | 53,263 m³ (연암·경암) | 약 +1,477, 분류 경계 확인 필요 |
| 어스앵커 | 79공 | 83공 | +4공 |
| C.I.P+H-PILE 천공 | ≈1,648 + ≈3,753 m | 1,796 + 3,692 m | CAP/케이싱 포함 여부 차이 |

### 구현
- import 단계에서 동일 공종 수량을 문서 간 대조 → 임계치(예: ±5%) 초과 시 경고 리포트.
- 생산성 원단위가 현장/이론 간 보정계수 임계치(예: <0.3 또는 >3) 벗어나면 `needs_review` 플래그.

## 5. 부수 개선 (후순위, 기존 모듈 활용)

- **공기↔손료 연동**: BOQ에 `H형강 손료 12개월`, `합성버팀보 손료 16개월(9+2서비스)` 등 존치기간 종속 비용 4억+ 존재. 가시설 존치기간 변동 시 손료 자동 증감 → "지연 1개월 = 손료 ○○원" 산출. EVM 확장.
- **계측 사유 추가**: `suggest_recovery` 회복 템플릿 사유에 `계측 경보`(지중경사계/지하수위/하중계) 추가 → 현재 5종(장비·검측·설계변경·협력사·기상) → 6종. 흙막이 현장 최대 리스크 반영.
- 계측 수량(지중경사계 11·지하수위계 11·하중계 2·변형률계 15·건물경사계 54·균열계 54·지표침하계 11·유량계 3)을 계측 마일스톤 입력으로.

## 6. 우선순위 & 의존성

```
기능1 (생산성 원단위)  ──┐
                         ├─> "BOQ 넣으면 공정표 초안" 핵심 루프 완성
기능2 (단계 모델/역산) ──┘
기능5 (교차검증)        ───> 신뢰성 확보 (1·2 산출물 검증)
부수개선 (손료/계측)    ───> 도메인 차별화 강화
```

권장 착수 순서: **1 → 2 → 5 → 부수개선**
