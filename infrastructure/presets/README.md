# 컬럼 매핑 프리셋

엑셀 개략공정표를 가져올 때 사용할 **컬럼 헤더 매칭표**입니다.
한 번 만들어 두면 같은 양식의 새 프로젝트에서 1초 만에 재사용됩니다.

## 사용 방법 (Streamlit 뷰어)
1. **3. Activity** 페이지 → `Excel 임포트` 클릭
2. **프리셋 선택** 드롭다운에서 `korean_standard` 같은 항목 선택
3. 파일 업로드 → 자동 매핑 → 임포트

## 직접 만들기
이 폴더의 JSON 한 개를 복사해서 양식에 맞게 헤더 이름만 바꾼 뒤
`column_mapping_우리회사.json` 같은 이름으로 저장하면 즉시 인식됩니다.

| 표준 필드명 (왼쪽) | 의미 | 필수 |
|---|---|---|
| `code` | 작업 고유 코드 (예: A-001) | ✅ |
| `name` | 작업 이름 | ✅ |
| `duration` | 기간 (영업일) | ✅ |
| `wbs_code` 또는 `wbs_id` | 상위 WBS 코드 | ✅ (둘 중 하나) |
| `discipline` | 공종 (위생/공조/소방/전기/자동제어/공통) | 선택 |
| `zone` | 시공 위치 (예: 1F-동측) | 선택 |
| `cost` | 직접공사비 | 선택 |
| `predecessors` | 선행작업 코드 (쉼표 구분) | 선택 |

오른쪽 값은 **엑셀의 실제 헤더 텍스트**와 정확히 같아야 합니다 (공백/괄호까지).
